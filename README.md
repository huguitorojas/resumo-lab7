# resumo-lab7

Neste laboratório exploramos as características do enriquecimento de IA da Azure. Para isso criamos um novo recurso de AI search clickando na aba AI Search, preenchendo os campos solicitados e após o review fazemos click em criar e está pronto. Logo devemos criar um novo recurso de Azure AI Service seguido. Em seguida devemos criar un Storage account preenchendo novamente os campos solicitados, com a particularidade que o nome deve ser único.

Dentro do storage que acabamos de criar devemos criar um novo container, e carregar os arquivos que vai alimentar o nosso modelo.

Logo voltamos no AI Search e clickamos em importar dados selecionando o nosso storage. O seguinte a fazer é abrir o search explorer e já podemos realizar as pesquisas no campo de busca.
